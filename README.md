# Golden Backpacks

Golden Backpacks is a NeoForge 1.21.1 mod that adds craftable, upgradeable backpacks with quick access, equipment support, and optional Curios/Accessories integration.

## Build

Use JDK 21, then run:

```powershell
.\gradlew.bat build
```

The built mod JAR is written to `build/libs/`.

## Features

- A progression of backpack tiers, from Frayed through Endless.
- Right-click and keybind access to backpack storage.
- Upgrade augments including filtering, farming, quiver, hopper, and loot features.
- Chest-slot equipment and optional Curios/Accessories compatibility.
